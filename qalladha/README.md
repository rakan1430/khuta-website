# قلّدها 🎙️

لعبة تقليد أصوات بين صديقين. يُعرض صوت — مواء قطة، صفّارة إسعاف، أو صوت
تسجّلونه بأنفسكم — ويقلّده كلّ منكما، ثم تُقارن التسجيلات بالأصل
وتُكشف النتيجتان معاً، وتسمعان تسجيل بعضكما (بأصوات مضحكة إن أردتما).

**الرابط:** <https://qalladha.netlify.app>

**وضعان:** جهازان عبر كود غرفة، أو جهاز واحد تتناوبان عليه.

---

## كيف تعمل

موقع مستقلّ تماماً، **لا علاقة له بموقع خُطى**. ملفات ثابتة فقط على
Netlify، والغرف في مشروع Supabase مستقلّ اسمه `qalladha` — لا دوالّ خادم
ولا خطوة بناء.

كل أصوات التحدي تُولّد في المتصفّح لحظياً (لا ملف صوتي يُحمّل)، ونسخة
التحليل هي نسخة التشغيل حرفياً فيسمع اللاعبان الشيء نفسه.

### الملفات

| الملف | العمل |
|---|---|
| `index.html` | الواجهة |
| `styles.css` | الهيئة |
| `js/audio.js` | توليد أصوات التحدي والمؤثرات والتسجيل |
| `js/scoring.js` | قياس قرب التقليد من الأصل |
| `js/net.js` | مناداة دوالّ الغرف في Supabase |
| `js/game.js` | مجرى اللعبة |

## الغرف وأمانها

جداول اللعبة في مخطّط `qalladha` وهو **غير مكشوف لواجهة REST إطلاقاً**،
فلا يستطيع أحد قراءتها ولا الكتابة فيها ولو عرف المفتاح. الوصول الوحيد
عبر عشر دوالّ مسمّاة، كل واحدة تتحقّق من صاحبها قبل أن تفعل شيئاً.

ومن القواعد المفروضة في قاعدة البيانات لا في الواجهة:

- **لا تُكشف نتيجة أحد ولا يُسلّم تسجيله قبل أن يسجّل الاثنان.**
- الغرفة لاعبان فقط، وصاحبها وحده يبدأ ويعيد ويسجّل التحدي المخصّص.
- تعاقب الجولات محميّ بقفل صفّ، فلا تقفز جولة حين يضغطان معاً.
- الغرفة تعيش اثنتي عشرة ساعة، ثم تُكنس تلقائياً عند أول إنشاء بعدها.

المفتاح المكتوب في `js/net.js` علنيٌ بطبيعته (publishable)، وموضعه الصحيح
هو كود المتصفّح، ولا يمنح إلا تنفيذ هذه الدوالّ.

## تعديل اللعبة وإعادة النشر

من داخل مجلد `qalladha/` على جهازك:

```bash
npx netlify-cli deploy --prod --dir .
```

ويسألك أول مرة عن تسجيل الدخول ثم عن الموقع — اختر `qalladha`
(في فريق `teacher wep`).

وإن ربطت الموقع بالمستودع من لوحة Netlify (Build & deploy ← Link repository،
والمجلد القاعدي `qalladha`)، صار كل دفع إلى الفرع يُنشر وحده.

> ⚠️ **لا تدمج هذا الفرع في `main`**: نشر خُطى يخدم جذر المستودع،
> وترويسة `Permissions-Policy` هناك تعطّل المايكروفون فتتعطّل اللعبة.

## كيف تُحسب النقاط؟

تُقارَن ثلاثة أشياء بين تسجيلك والأصل:

- **النبرة** — شكل الطيف عبر 24 حزمة مِل، بمحاذاة زمنية (DTW) تتسامح مع
  كونك أبطأ أو أسرع قليلاً.
- **النغمة** — مسار الطبقة صعوداً وهبوطاً، بالارتباط الذاتي في مدى
  70–1000 هرتز.
- **الإيقاع** — منحنى الطاقة: متى يعلو الصوت ومتى يسكت.

ارتفاع صوتك لا يفيدك: يُطبّع المستوى قبل المقارنة.

**وبصراحة:** هذه مقارنة تقريبية لأشكال موجات، لا أذن خبير. عويرت على
إشارات مُصطنعة (صوت مطابق ≈ 99، تقليد قريب ≈ 93، صوت مختلف ≈ 6،
ضجيج ≈ 35) لكنها لم تُختبر بعد على أصوات بشرية حقيقية. إن وجدتماها
قاسية أو كريمة أكثر من اللازم، الثوابت الثلاثة في أعلى دالّة المعايرة
في `js/scoring.js` تضبطها:

```js
const FLOOR = 0.26, SPAN = 0.67, CURVE = 0.85;
```

- أنقص `FLOOR` ← الجميع يأخذ نقاطاً أكثر.
- أنقص `CURVE` ← المتوسّطات ترتفع.
