# قلّدها 🎙️

لعبة تقليد أصوات بين صديقين. يُعرض صوت — مواء قطة، صفّارة إسعاف، أو صوت
تسجّلونه بأنفسكم — ويقلّده كلٌّ منكما، ثم تُقارن التسجيلات بالأصل وتُكشف
النتيجتان معاً، وتسمعان تسجيل بعضكما (بأصوات مضحكة إن أردتما).

**وضعان:** جهازان عبر كود غرفة، أو جهاز واحد تتناوبان عليه.

---

## النشر — دقيقة واحدة

اللعبة موقع مستقل تماماً، **لا علاقة له بموقع خُطى**. لا يحتاج GitHub ولا
قاعدة بيانات: الغرف تُخزَّن في Netlify Blobs الذي يعمل بلا أي إعداد.

### الطريقة الموصى بها (سطر واحد)

من داخل مجلد اللعبة على جهازك:

```bash
npx netlify-cli deploy --prod
```

سيسألك أول مرة أن تسجّل الدخول (يفتح المتصفح)، ثم:
- اختر **Create & configure a new project**
- اختر فريقك، وسمِّ الموقع مثلاً `qalladha`
- حين يسأل عن مجلد النشر اكتب نقطة: `.`

ينتهي فيعطيك رابطاً مثل `https://qalladha.netlify.app` — هذا هو الرابط
الذي ترسله لصديقك.

### الطريقة الثانية (بلا أوامر)

اسحب المجلد كاملاً وأفلته في <https://app.netlify.com/drop>.
لو ظهرت الغرف لا تعمل بعدها، فالسبب أن الدالة لم تُحزَم في هذا الأسلوب —
استخدم الطريقة الأولى.

---

## بعد النشر

1. افتح الرابط، اكتب اسمك، واضغط **أنشئ غرفة**.
2. اضغط **أرسل الرابط لصديقك** — الرابط يحمل كود الغرفة معه.
3. حين يدخل، اضغط **ابدأوا**.

المايكروفون يعمل على HTTPS فقط، و Netlify يخدم HTTPS دائماً.

## كيف تُحسب النقاط؟

تُقارَن ثلاثة أشياء بين تسجيلك والأصل:

- **النبرة** — شكل الطيف عبر 24 حزمة مِل، بمحاذاة زمنية (DTW) تتسامح مع
  كونك أبطأ أو أسرع قليلاً.
- **النغمة** — مسار الطبقة صعوداً وهبوطاً، بالارتباط الذاتي في مدى
  70–1000 هرتز.
- **الإيقاع** — منحنى الطاقة: متى يعلو الصوت ومتى يسكت.

ارتفاع صوتك لا يفيدك: يُطبَّع المستوى قبل المقارنة.

**وبصراحة:** هذه مقارنة تقريبية لأشكال موجات، لا أذن خبير. عايرتُها على
إشارات مُصطنعة (صوت مطابق ≈ 99، تقليد قريب ≈ 90، صوت مختلف ≈ 6، ضجيج ≈ 35)
لكنها لم تُختبَر بعد على أصوات بشرية حقيقية. إن وجدتماها قاسية أو كريمة
أكثر من اللازم، الثوابت الثلاثة في أعلى دالّة المعايرة في
`js/scoring.js` تضبطها:

```js
const FLOOR = 0.26, SPAN = 0.67, CURVE = 0.85;
```

- أنقص `FLOOR` → الجميع يأخذ نقاطاً أكثر.
- أنقص `CURVE` → المتوسّطات ترتفع.
